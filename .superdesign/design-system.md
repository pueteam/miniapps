# Miniapps Home
## Purpose
Spanish-language launcher for five independent utility and productivity PWAs. Help users identify and open the right tool. Preserve actual registry titles, descriptions and URLs. No invented metrics, users, claims or new product features.
## Brand
Manrope body/UI, Sora headings. Blue #004f87, hover #0a5b95, supporting blues from styles/base.css. White #fff, warm soft page #f7f7f5, text #4a4f57, neutral dark #1b1f26, borders #e8eaed. Pink #d10053 only as a restrained accent if needed. No logo exists in the current launcher; retain the Miniapps wordmark as text.
## Layout and components
Max-width 1280px, fluid 20–48px horizontal gutters. Spacing 4/8/12/16/20/24/32/40/48/64px. Radius 8/16/24px, pills 999px. Subtle borders and soft shadows. Card grid automatically wraps, minimum 240px. White linked cards and clear focus-visible outlines. Typography with concise labels, Sora headlines and comfortable Manrope descriptions. Iconography: compact outline SVG, blue on tinted blue surface; no emoji.
## Redesign direction
Professional, calm utility directory: slim wordmark/repository header; generous welcome block with a subtle blue surface; clear section heading and real dynamic app count; balanced card grid with visual identity, category labels and aligned opening affordances. Preserve all five tools and actual hrefs. No fabricated thumbnails or decorative photography. Mobile stacks without horizontal overflow. No search/filter functionality in this visual-only scope. Respect reduced motion; hover transitions 120–220ms.
## Existing source
Current UI has only a title and repository description, followed by the card grid. Source reproduction must match those files exactly; redesign may add presentational header/section/footer and SVG card icons. Do not modify global brand tokens or sibling apps.
